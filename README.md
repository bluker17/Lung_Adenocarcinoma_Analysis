## Project Description:

This investigation is a final independent analysis project for University of North Carolin at Charlotte's BINF6310: Advanced Statistics for Genomics. The GSE40419 dataset, which contains RPKM-normalized RNA-seq data for surgically removed lung adenocarcinoma and normal adjacent lung tissues in a Korean population, was analyzed to reveal differential gene expression between paired tissue samples, as well as identify the impact of smoking on lung adenocarcinoma mechanisms.
